# Hunting Ground

This repository contains the first playable vertical slice of a portrait 3D boss-rush prototype made in Godot 4.7.

The current slice focuses on sword combat feel: directional attacks selected by the right joystick, movement, dodge, lock-on, health, fatigue, one boss, and local progression state.

Kenney assets are used from the local collection. The sword model is from `Early access/Medieval Weapons`/`Mini Arena`, and the character source assets are retained in `assets/kenney` for continued iteration.
