# Writing specs

Read both files in the project root and follow them:

- `Speccing.md` — what a spec contains, its style, its minimalism, and how to
  review it with the user one item at a time.
- `Philosophy.md` — design and writing principles for code, specs and
  documents in this project.

Chat with the user stays plain (see the plain-talk skill). Specs and design
documents follow these two files instead; that is a different style on
purpose.
