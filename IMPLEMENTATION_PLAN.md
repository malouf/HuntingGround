# Implementation Plan

## Milestone 1: sword vertical slice

- Create the portrait Godot project.
- Add hub, loadout, fight, victory, and defeat flow.
- Add Kenney sword model and retained Kenney character source assets.
- Add movement, camera orbit, lock-on, dodge, health, fatigue, and local save.
- Add one boss telegraph and a readable melee punishment window.

## Milestone 2: sword feel pass

- Import and retarget Kenney idle/run/attack animations.
- Replace procedural actor bodies with the selected character model and skin.
- Add sword attack poses, hit pause, hit reactions, damage flash, audio, and better camera framing.
- Tune joystick deadzones, attack direction thresholds, combo timing, stamina recovery, and boss telegraph duration.

## Milestone 3: sword content pass

- Add item slots without crafting.
- Add the first three boss variations using data resources.
- Add unlock selection and a more visual hub.
- Test an Android build on the Samsung S22.

## Milestone 4: bow experiment

- Add hold duration to the right joystick contract.
- Prototype aim, draw, release, projectile collision, and target lock behavior.
- Compare bow readability and input comfort with sword controls before expanding the weapon roster.
